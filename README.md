Dokkan (دكان) 🛒

Hey there! Welcome to Dokkan—a simple, lightweight online store project I built to sell products online without the headache of setting up a massive backend or complex build tools.

The coolest thing about this project? Everything lives inside a single HTML file. Yep, HTML, CSS, JavaScript, and Firebase are all bundled together in one place. No complicated folder structures, just drop it in and watch it work!

✨ Features

Product Catalog: Browse through items easily.

Firebase Integration: Real-time database magic to handle product data and user interactions smoothly.

Zero Build Tools: No Webpack, no Vite, no npm install madness. Just pure, straightforward code.

Responsive Styling: Clean CSS that looks good whether you're checking it on your laptop or phone.

🛠️ Tech Stack

I kept the stack super lean and beginner-friendly:

HTML5 (The skeleton)

CSS3 (The styling & layout)

JavaScript (ES6+) (The logic and interactivity)

Firebase (Backend-as-a-service for database/auth)

🚀 How to Run It

Since everything is in a single file, running it is ridiculously easy:

Clone or download this repository.

Open the main HTML file (e.g., index.html) in any web browser.

Optional: If you want to connect your own Firebase backend, just update the Firebase configuration keys inside the <script> tag in the file.

💡 Why did I build this?

I wanted to build a quick, hassle-free e-commerce prototype that showcases how powerful vanilla web technologies can be when combined with Firebase, without needing a bloated framework.
